# Korben.info: pitch for Nosy Notch

Korben (Manuel Dorne) has written about **boring.notch** and **Notchi**, in several languages (FR, EN, DE, ES, JA). That makes him the best contact outside Reddit. He writes in French; a short, personal email with a video link works better than a press release.

## Where to send it

- **Press contact:** on [korben.info/presse](https://korben.info/presse/) (the address is shown there, not copied here because it's obfuscated on the page).
- **Fallback:** `korben@korben.info` (listed in [korben.info/en/llms.txt](https://korben.info/en/llms.txt) as the general/commercial contact).
- Check whether the reader news form from [“Vos news sur Korben.info”](https://korben.info/vos-news-sur-korbeninfo.html) is live; if so, submit the short version there too.

## Before sending

- [ ] v0.3.0 released, `npx nosynotch` works from npm
- [ ] The promo video is online with a link that plays in the browser (e.g. as an asset of the GitHub release, embedded in the README, or an unlisted YouTube video). Don't attach the 14 MB MP4.
- [ ] README starts with the Nosy video, website shows Nosy
- [ ] Send Tuesday–Thursday morning (French time). No follow-up before a week; then one short follow-up at most.

## Email (English, if you'd rather write in English)

**Subject:** Nosy Notch: a tiny helper in the MacBook notch that watches Claude Code (free, open source)

```
Hi Korben,

I've been reading your posts for a while, including the ones on boring.notch and Notchi, so I thought this might interest you: Nosy Notch.

It's a free, open-source macOS app (MIT) that turns the MacBook notch into a small control spot for AI coding agents (Claude Code, Codex, Cursor). A little character called Nosy lives in it:

- he shows live what the agent is doing
- when the agent asks for permission, he waves and you click Allow right in the notch
- when it's done, he cheers; you read the answer and can reply without switching windows

- on the side: music player, file shelf with AirDrop, meeting reminders, battery, AirPods and a focus timer

Everything stays on your Mac, no account, no telemetry. Install: npx nosynotch (macOS 14+).
```
